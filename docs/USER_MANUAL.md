## 1. 产品简介

BlockoutStudio 是一个**独立打包的 Windows 桌面程序**（非 UE 编辑器插件），面向关卡设计师搭建 3D 游戏白盒关卡（类 CS:GO / 类魂 / 类神海），支持：

- **参数化体块库**：18 种预设形状（基本体 + 建筑构件 + 自由网格），参数驱动实时重建；
- **专业物件编辑**：变换 gizmo、世界/本地坐标系、网格吸附、表面吸附、复制/阵列/镜像/对齐、分组、撤销重做（150 步）；
- **点线面建模**：ProBuilder 式推拉/挤出/倒角/塌陷/焊接/内插/细分/删面/翻转法线；
- **三类挖洞**：门/窗构件拖墙自动开洞、房间/走廊自动连通、自定义多边形轮廓挖洞；
- **测试跑图**：UE 官方小白人（Manny/Quinn）FPS/TPS 双视角、走/跑/蹲/跳、CS/魂/神海 三套角色尺度预设；
- **录制**：轨迹录制回放 + 视频录制（AVI 原生录制，内置 ffmpeg 自动转封装产出 MP4/WebM）；
- **出图**：两点测距/尺寸标注、2D 俯视图导出 PNG/SVG；
- **数据可靠**：自动保存、快照回滚、崩溃恢复、JSON 工程文件、OBJ/FBX/glTF/GLB/USD 导出、OBJ/glTF 导入。

## 2. 安装与运行

### 2.1 方式一：直接运行便携版（推荐）

1. 获取打包产物目录 `Packaged\Windows\`（或对应 zip 便携包）；
2. 双击 `BlockoutStudio.exe` 即可进入编辑器，无需安装 UE；
3. 依赖已随包分发（含 `ThirdParty\ffmpeg\ffmpeg.exe`，由构建系统 RuntimeDependencies 自动复制到输出目录）。

### 2.2 方式二：从源码编译

**环境要求**

| 项 | 要求 |
|---|---|
| 引擎 | UE 5.6.1（本项目开发环境路径 `F:\UE_5.6`） |
| IDE | Visual Studio 2022（含 C++ 游戏开发工作负载） |
| 系统 | Windows 10/11 x64 |
| 工程路径 | `E:\BlockoutStudio\BlockoutStudio.uproject` |

**编译编辑器（日常开发）**

```bat
F:\UE_5.6\Engine\Build\BatchFiles\Build.bat BlockoutStudioEditor Win64 Development -project="E:\BlockoutStudio\BlockoutStudio.uproject" -waitmutex
```

**Shipping 打包（便携版）**

```bat
F:\UE_5.6\Engine\Build\BatchFiles\RunUAT.bat BuildCookRun -project="E:\BlockoutStudio\BlockoutStudio.uproject" -platform=Win64 -clientconfig=Shipping -build -cook -stage -pak -prereqs -archivedirectory="E:\BlockoutStudio\Packaged\Windows" -unattended
```

完整耗时约 1–3 分钟（增量）。打包注意事项见 [FAQ 14.2](#14-常见问题faq)。

### 2.3 双击运行

- exe 位于 `Packaged\Windows\BlockoutStudio.exe`；
- 启动后直接进入**编辑模式**，中文 UI；
- 日志与自动保存文件在程序 `Saved\` 目录下。

## 3. 界面布局

编辑模式 UI 采用 UE 编辑器风格三区布局：

```
┌─────────────────────────── 菜单/工具栏 ───────────────────────────┐
│  文件(保存/加载/导出/导入)  变换模式(W/E/R)  坐标系(B)  吸附(G/S)   │
│  撤销/重做  快捷工具(对齐/镜像/阵列/分组)  视图模式  帮助           │
├──────────────┬──────────────────────────────┬────────────────────┤
│  创建面板     │                              │  属性面板           │
│ (左侧)        │        3D 视口 Viewport       │  位置/旋转/缩放     │
│ 缩略图网格卡片│        （编辑/跑图）           │  尺寸/颜色/贴图     │
│ 6 基本体笔刷  │                              │  ──────────        │
│ 12 建筑预制件 │                              │  场景树（物件列表）  │
│              │                              │  搜索/多选/拖拽      │
│              │                              │  右键菜单/可见性     │
├──────────────┴──────────────────────────────┴────────────────────┤
│                        底部快捷键提示条                            │
└───────────────────────────────────────────────────────────────────┘
```

### 3.1 左侧：创建面板（带缩略图的网格卡片）

- **基本体笔刷 6 种**：立方体、圆柱、球、胶囊、楼梯、斜坡（Wedge/楔形等，以面板实际为准）；
- **建筑预制件 12 种**：墙、拱门、门洞墙、窗洞墙、管道、柱廊、围墙、楼梯间、地板、门构件、窗构件等；
- 每个卡片为**网格布局**：Slate 程序绘制的形状缩略图（88x54 预览框，按形状几何轮廓实时绘制线框）+ 名称文字，每行 3 个，悬停有 Tooltip 说明；
- **操作**：单击卡片即在视口中央（或鼠标拾取点）放置该体块；放置后在右侧属性面板调参。

### 3.2 顶部：菜单/工具栏

文件操作（保存 P、加载、导出、导入）、变换模式切换（移动 W / 旋转 E / 缩放 R）、坐标系切换（B）、网格吸附（G）与步长（1/5/10/25/50/100 cm）、表面吸附（S）、撤销/重做（Z/Y）、对齐/镜像/阵列/分组快捷工具、视图模式（光照/无光照/线框）、测试模式（F5）、录制（F9）。

### 3.3 右侧：属性面板 + 场景树

- **属性面板**：选中物件的名称、位置/旋转/缩放（数值输入与 gizmo 双向同步）、形状参数（长宽高/段数/台阶数等）、颜色（调色板 + 拾色器）、贴图样式（Grid/棋盘格/砖墙/混凝土/瓷砖/金属板）与平铺密度、分组信息；
- **场景树（物件列表）**：
  - **搜索过滤框**：按名称或形状类型关键词实时过滤；
  - **多选**：Ctrl+点击加选/减选、Shift 范围选、Ctrl+A 全选；
  - **类型图标**：每行显示该体块形状的迷你预览图标 + 名称；
  - **双击重命名**：行内编辑，回车提交；
  - **可见性/锁定开关**：每行右侧独立 CheckBox，立即生效并入撤销栈；
  - **拖拽排序**：拖到行上方/下方调整场景中物件顺序；
  - **拖拽编组**：拖到某行**上方目标行本体（Onto）**即把拖拽项编入目标组（GroupId）；
  - **右键菜单**：重命名 / 复制 / 删除 / 隐藏 / 显示 / 锁定 / 解锁 / 编组 / 解组 / 全选 / 清空选择；
  - 场景树选择与视口选中**双向同步**（含低频轮询兜底刷新）。

### 3.4 底部：快捷键提示条

常驻显示当前模式与高频快捷键，`Tab` 可隐藏/显示整个 UI。

## 4. 编辑模式：物件编辑

### 4.1 选择

| 操作 | 方法 |
|---|---|
| 单选 | 左键点击物件 |
| 多选 | Ctrl+点击加选/减选 |
| 框选 | 空白处按住左键拖出选框 |
| 全选 | A |
| 取消选择 | Escape / 点空白处 |

### 4.2 变换 gizmo（M2 级手柄）

- **切换模式**：W 移动 / E 旋转 / R 缩放（或工具栏按钮）；
- 拖拽三轴手柄操作；多选时整体变换；
- **PMB 式尺寸手柄**：选中体块后 6 个面各有一个拖拽手柄，直接拖拽实时改尺寸（与属性面板数值联动）。

### 4.3 世界/本地坐标系（E3）

- 按 **B** 在 世界(World) / 本地(Local) 间切换；
- 切换后 gizmo 轴向随物件朝向变化，与属性面板数值严格一致（数学正确性为本工具红线）。

### 4.4 吸附

- **网格吸附**：G 开关；步长在工具栏选择 1 / 5 / 10 / 25 / 50 / 100 cm；
- **表面吸附**：S 开关；移动时吸附到其他物体的面/边/角，自动贴合对齐、不穿插。

### 4.5 复制 / 阵列 / 镜像 / 对齐（E7）

| 功能 | 操作 |
|---|---|
| 复制 | Ctrl+D 或 Ctrl+拖拽 |
| 阵列 | 工具栏"阵列"→ 线性/环形，设置数量与间距 |
| 镜像 | 工具栏"镜像"→ X / Y / Z |
| 对齐 | 8 种：左/右/前/后/顶/底/水平居中/垂直居中 |

### 4.6 撤销/重做（E8）

- Z 撤销 / Y 重做；深度 150 步；
- 所有编辑操作（含隐藏/锁定/重命名/拖拽排序/编组）均入撤销栈。

### 4.7 分组 / 隐藏 / 锁定（E9）

- O 打组 / U 解组；也可场景树右键或把条目拖到目标行（Onto）编组；
- 隐藏/锁定：场景树行内 CheckBox 或右键菜单；锁定物件不可被视口选中编辑。

## 5. 编辑模式：建模能力

### 5.1 放置与参数化体块（M1）

1. 左侧创建面板点击缩略图卡片放置体块；
2. 右侧属性面板修改长宽高/段数/台阶数/弧度等参数，**实时重建**。

支持 18 种形状：Cube / Wall / Staircase / Ramp / Wedge / Arch / DoorWall / WindowWall / Cylinder / Sphere / Capsule / Pipe / Colonnade / Fence / Stairwell / Floor / DoorPiece / WindowPiece / Custom（自由网格）。

### 5.2 手柄拖拽改尺寸（M2）

选中体块 → 拖拽 6 面手柄 → 实时改尺寸，与属性面板双向联动。

### 5.3 点线面编辑（M3）

进入子层级模式（**F8**），选点/边/面后可用：

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 推拉（移动子元素） | X | 挤出前推拉 |
| 挤出 | X | 沿法线挤出选中面 |
| 倒角 | C | 顶点/边倒角 |
| 塌陷 | V | 合并选中点 |
| 内插面 | T | Inset |
| 细分 | K | 细分面 |
| 翻转法线 | J | 翻面 |
| 补洞 | H | Fill Holes |
| 焊接 | N | Weld 重合顶点 |

**注意**：进入点线面编辑后体块转为**自由网格（Freeform）**，布尔/挖洞结果同样持久化为自由顶点+三角数据，可继续参与后续布尔与撤销链路。

### 5.4 挖洞（M4）

1. **预设构件开洞**：把门构件（DoorPiece）/窗构件（WindowPiece）拖到墙上 → 自动对齐并布尔开洞（Auto-Align）；
2. **自动连通**：房间/走廊块靠近时自动检测连接面开门洞连通；
3. **自定义轮廓挖洞**：选中体块 → 工具栏"自定义挖洞" → 在面上画矩形/多边形/圆形轮廓 → 拉伸深度可调（贯穿或盲孔）。

布尔结果无坏面（法线/非流形处理见 `FBlockoutMeshEditLib`）。

### 5.5 快速生成（M5）

- 门洞墙一键生成（DoorWall）；
- 柱廊/围墙阵列（Colonnade/Fence，参数 ArrayCount/ArraySpacing）；
- 楼梯间（Stairwell）。

## 6. 材质与外观

| 编号 | 功能 | 操作 |
|---|---|---|
| A1 | 分色预设 | 属性面板调色板：地面/墙体/障碍/可交互/装饰/危险（白盒灰阶+强调色） |
| A2 | 基础贴图 | 属性面板 Pattern：Grid（ProBuilder 风格网格，复用 PMB T_Grid 观感）/ Checker / Brick / Concrete / Tile / MetalPlate；Tiling 平铺密度可调 |

## 7. 测量与出图

- **两点测距（T1）**：按 **M** 进入测距模式 → 点两个点 → 实时显示长度/高度差/角度 → **Enter** 确认并把尺寸标注留在场景中；
- **2D 俯视图（T2）**：工具栏"2D 出图"→ 可选是否带尺寸标注/网格/名称 → 导出 **PNG**（位图）与 **SVG**（矢量）；
- **比例尺参考（T3）**：工具栏"比例尺"→ 生成 1m / 2m / 1.8m 人形参考体（灰色锁定，仅作尺度对照）。

## 8. 测试模式（跑图）

### 8.1 进入/退出

- **F5** 一键进入测试模式；**Escape 或 F5** 退出回到编辑现场（编辑状态完整保留）。

### 8.2 操作（UE 官方小白人模板）

| 操作 | 按键 |
|---|---|
| 移动 | WASD |
| 视角 | 鼠标 |
| 跑 | Shift（按住） |
| 蹲 | Ctrl 或 C |
| 跳 | Space |
| FPS/TPS 切换 | V（FPS=官方第一人称手臂；TPS=官方 SpringArm 第三人称） |
| 切换角色 | B（Manny / Quinn） |
| 尺度预设 | 1=类CS:GO / 2=类魂 / 3=类神海 |
| 跳跃测量 | 起跳后自动统计跳高/跳距并显示（P5） |

- 碰撞使用 UE 官方 CharacterMovement，不穿墙、可上楼梯、斜坡可走、可跌落；
- 测试模式锁定鼠标，ESC 释放。

## 9. 录制与演示

### 9.1 轨迹录制与回放（R1）

1. 测试模式中按 **F9** 开始录制（界面有录制状态指示）；
2. 跑图结束按 **F9** 停止；
3. 菜单"轨迹回放"→ 可反复回放审阅（插值平滑回放）。

### 9.2 视频录制（R2）

- 录制结束时自动出成品视频，输出目录为工程 `Saved\Video\`（或录制时指定的输出目录）：
  - **AVI（MJPEG）**：录制过程原生产出，可正常播放；
  - **MP4（H.264）/ WebM（VP8）**：由内置 **ffmpeg**（`ThirdParty\ffmpeg\ffmpeg.exe`，LGPL 动态链接方式随包分发）自动转封装产出双成品；
- 快捷入口：F9 开始/停止，录制状态可见（R3）。

## 10. 导出与导入

### 10.1 导出（D3）

工具栏"导出"→ 选择格式与选项（按物体/按材质分组）：

| 格式 | 说明 |
|---|---|
| OBJ | 直导，含正确变换 |
| FBX | 自动中转产出（面向 Unity：Y-up、cm 单位，Unity 导入自动换算；1uu=1cm） |
| glTF/GLB | 米制规范，Y-up |
| USD | 附加支持 |

- 已实测：UE 5.6.1 四格式导入无报错、bounds 完全一致（样例 `[450.02,400.02,200.02] cm`）；
- Unity 导入：格式/单位已按 Unity 规范修正，样例在会话输出 `d3_export` 目录可供复验。

### 10.2 导入（D4）

菜单"导入"→ 支持 **OBJ / glTF** 导入为参考体（ReferenceMesh），用于对照布局，不参与体块编辑。

## 13. 命令行自动化

打包版 exe 支持以下自动化参数（CI/批量验证用）：

| 参数 | 作用 |
|---|---|
| `-AutoExportTest=<输出目录>` | 自动导出 4 格式样例并退出 |
| `-AutoPerfTest=<体块数>` | 自动压测（如 1000）输出 perf_report.json |
| `-AutoCollisionTest=<关卡JSON>` | 自动碰撞回归（overlap/penetration 统计） |
| `-AutoDemoLevel=<关卡JSON> -AutoDemoOut=<输出目录>` | 自动鸟瞰截图 + 跑图录像后退出 |

示例：

```bat
BlockoutStudio.exe -AutoDemoLevel="E:\BlockoutStudio\Content\Levels\level_dust2_final.json" -AutoDemoOut="E:\BlockoutStudio\Saved\DemoOut"
```

内置示例关卡 JSON：`Content\Levels\`（dust2_final / dustyard / souls_castle / uncharted_ruins，各含 demoPath 演示轨迹）。

## 14. 常见问题（FAQ）

### 14.1 启动即崩溃 / 黑屏

- 确认显卡驱动支持 DX12/SM5；
- 删除 `Saved\Config\` 后重启让配置重建；
- 查看 `Saved\Logs\` 下日志定位报错。

### 14.2 Shipping 打包失败

- **DesktopPlatform 报错**：引擎 DesktopPlatform 模块许可不允许再分发，本项目已改用 Win32 通用文件对话框（`FBlockoutFileDialog`），不要引用 `IDesktopPlatform`；
- **GetActorLabel / IsHiddenEd 等编译错**：这是编辑器 Only API，Shipping 下不存在；应改用 `GetActorNameOrLabel()` / `IsHidden()`，涉及编辑器专属数据用 `#if WITH_EDITORONLY_DATA` 包裹。Shipping 打包前请全局搜索这些 API 残留；
- 打包命令见 [2.2](#22-方式二从源码编译)。

### 14.3 视口截图全黑

运行时 `ReadPixels` 在 Shipping 下常读到全黑，应改用 `SceneCaptureComponent2D` 截图，并配 `DirectionalLight(强度约 8) + SkyLight(强度约 1.2)` 固定曝光。

### 14.4 相邻体块表面闪烁（Z-fighting）

共面体块已做 +0.02uu 膨胀偏移处理；若自定义几何仍闪烁，避免两平面完全共面。

### 14.5 源文件中文乱码 / 编译报错奇怪字符

所有 C++ 源文件必须保存为 **UTF-8 with BOM + CRLF** 换行（`.md` 文件 frontmatter 前不要加 BOM）。

### 14.6 录制/演示动画卡顿或无效

- `AutoDemoTimer` 间隔需 ≥0.1s，过小会失效；
- 自动演示机位请用 `AutoDemoPlacedShot` 标记法放置机位，勿用裸 Timer 驱动。

### 14.7 视频只有 AVI，MP4/WebM 在哪

录制结束后由内置 `ThirdParty\ffmpeg\ffmpeg.exe` 自动转封装；若缺失 ffmpeg.exe，从 `ThirdParty\ffmpeg\` 手动复制到打包输出目录即可。

### 14.8 网格/几何 API 报错

- `TBulkData::Realloc` 需先 `Realloc` 再 `Lock`；
- `FPlatformProcess::CreateProc` 返回 `FProcHandle`（不是 `void*`）；
- `ComputePenetration` 签名：`(FMTDResult&, const FCollisionShape, FVector, FQuat)`；
- Slate 拖拽：`FDragDropOperation` 在 `Input/DragAndDrop.h`；拖拽接收委托（OnCanAcceptDrop/OnAcceptDrop）挂在 `STableRow` 而非 `SListView`；
- `FSlateDrawElement::MakeBox` 需要 `const FSlateBrush*`（取局部 `FSlateColorBrush` 的地址）；`OnPaint` 第 3 参数为 `const FSlateRect&`（UE 5.6）。

### 14.9 git / 推送问题

- 推送走本地代理 `127.0.0.1:26001`（仓库已配置 http/https proxy）；
- `Packaged/**` 由 Git LFS 管理；`*.uasset/umap` 不走 LFS（防止超过 LFS 1GB 免费额度），全部资产直接入 git。
